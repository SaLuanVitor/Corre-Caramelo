# 🍬 Corre Caramelo

Um jogo arcade 2D onde um cachorro caramelo precisa sobreviver, coletar comida e fugir das crianças até encontrar um novo lar.

---

## 🎮 Gameplay

- Explorar fases
- Coletar comida
- Recuperar estamina
- Fugir das crianças
- Sobreviver
- Avançar para próxima fase

---

## 🛠️ Tecnologias

- Unity 6+
- C#
- Input System
- Cinemachine
- TextMeshPro
